# 最终返回标准（每家公司成稿必须包含）

适用于所有公司（美股 / 港股 / A 股）。与网站「研究笔记 → 研究标准 → 最终返回标准」保持一致；改一处请同步另一处。

| # | 模块 | 必含内容 | 最低要求 |
|---|---|---|---|
| 0 | 头部信息 | 公司 / 代码 / 市场；研究日期；价格锚点（收盘或盘中要写明）；财报期；主要数据来源 | 一行写完，缺任何一项都要标 [MISSING] |
| 1 | 公司简介 | 做什么的、靠什么赚钱、在行业里的位置；最近一次大事件（并购、分拆、减值、CEO 更替等） | 3–5 句，先让读者知道这是一家什么公司 |
| 2 | 业务分布 | 按分部/产品/地区拆收入（或利润）占比；指出利润集中在哪一块 | 至少列出前 3 个分部及占比，取不到的写 [MISSING] |
| 3 | 优势与缺点 | 优势与缺点各 3 条左右，对应护城河、成本结构、财务与治理短板 | 每条要有事实或数字支撑，不写空话 |
| 4 | 行业趋势 | 所处行业的供需、周期位置、政策与技术变量；对这家公司是顺风还是逆风 | 3–4 条，区分“事实”和“判断”，并说明对本公司的传导路径 |
| 5 | 结论卡 | 评级；一句话结论；预期盈亏比；确定性（高/中/低）；增长可持续期限（到 2027 年底？更长？） | 3–5 句，必须给方向，不写“两边都有道理” |
| 6 | 关键指标 | 估值：TTM PE / 动态 PE / PEG / PB 或 EV/EBIT；增长：收入、EPS、FCF；质量：毛利率、ROE/ROIC、现金流/净利润；杠杆 | 每项带口径（GAAP/调整后、TTM/指引）与日期 |
| 7 | 增长与护城河 | 增长来源拆解（量/价/份额/结构/并购/周期）；能否持续到 2027 年底；护城河；AI 是否为可量化变量 | 至少 3 条，每条有数字或可观察事实 |
| 8 | 三情景估值表 | 悲观 / 基准 / 乐观：盈利假设、倍数、隐含价、上下行幅度、触发/证伪条件；盈亏比推导；概率假设 | 概率与期望收益必须注明是研究假设，不是回测胜率 |
| 9 | 结论与买入纪律 | 评级理由；合理买入区；确认加仓条件；减仓 / 止盈条件；失效条件；仓位原则 | 价位必须写明由“情景 EPS × 倍数”反推，并标为条件化研究区间 |
| 10 | 风险与证伪 | 3–5 条可观察、可量化、有时间约束的证伪条件；最大的一个反证要单独点名 | 不能只写“行业竞争加剧”这类泛泛表述 |
| 11 | 多空交锋 | 多头最强论点；空头最强论点；裁决及理由 | 空头必须逐条回应多头；缺则写“未做对抗检验” |
| 12 | 口径与陷阱 | 一手/二手来源；第三方冲突及处理；被清洗的一次性项目；本页所有 [MISSING] 清单 | 冲突以公司一手公告为准并写明 |
| 13 | 后续验证日历 | 下次财报日期；关键变量与验证阈值；重评触发条件 | 有日期的写日期，没有的写“待公告” |
| 14 | 免责声明 | 本报告仅供研究参考，不构成个人投资建议 | 每份输出结尾必带 |

## 深度分级

- **完整版**（模块 0–14 全部）：首次覆盖、进入观察名单、评级变化、财报后的重估
- **简版**（模块 0、1、5、6、9、10、12）：同一批的横向比较、已有完整版之后的季度跟踪
- **批次汇总页**：横向对照表（统一口径）+ 排序与理由 + 共同变量 + 数据陷阱记录 + 与上一批的衔接 + 下一批；每批 3–5 家公司一份，放在个股页之前

对话里的即时回复用“简版 + 三行结论”（评级、盈亏比、最大风险），完整版放进文件或研究页；不要在对话里只给一句评级。

## 写入网站

`BusinessWeb/src/data/companies.ts` 的公司条目要尽量填满：`metrics`（含 `Bear / Base / Bull`、价格锚点、Base / Bear 赔率）、`thesis`（增长与护城河）、`risk`（含证伪线）、`next`（含买入区、加仓、减仓、下次财报）。公司二级页会按本标准显示“完整度”，缺项显示“待补充”。
