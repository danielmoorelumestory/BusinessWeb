# 附：迁移时最容易丢失、但最影响输出质量的 6 条


1. **变异认知驱动** — 说不出「市场错在哪里」就标「监控项」或「放弃」，不写「好公司便宜」式泛论。
2. **数据可追溯** — 缺失写 `[MISSING]`，超 90 天写 `[STALE]`，绝不凭空编数字。
3. **财报时效性** — 先判断此刻能拿到的最新一期财报是什么（A股：一季报4月底/中报8月底/三季报10月底/年报次年4月底；美股：10-Q 季报、10-K 年报；港股：中报9月底、年报次年3月底），再去取数，不要默认拉年报。
4. **估值必须多方法交叉验证** — 至少两种方法论 + 牛/基本/熊三情景 + 敏感性矩阵 + 显式列出 WACC、增长率、折现期；终值占比 >75% 须警示。
5. **每个论点必须有可证伪条件** — 可观察、可量化、有时间约束。
6. **给方向，不骑墙** — 禁止无结论的「两边都有道理」，必须出 Buy/Hold/Sell + 目标价 + 时间维度。
