# 研究方法 · 适用于所有公司

来源：src/data/notionNotes.ts 的 researchStandard，由 scripts/generate-investment-method.mjs 同步生成，完整保留网站研究方法。程序化补全批规则见 screening-rules.md。

适用时以统一入口 SKILL.md 的冲突处理为准；个人仓位规则仅在用户采用本项目策略时适用，交易分析的三方风险裁决按任务选用。

## 核心投资目标

在合理价格买入盈利趋势向上、确定性较高、增长持续时间更长、并且预期盈亏比有吸引力的股票。先算下行，再谈上行；先验证赚钱能力，再讨论概念。

## 适用范围与项目研究页约定

- 适用于美股、港股、A 股；统一研究标准，按公司核实会计与币种，按市场和证券类型核实交易制度

- 每家公司一个独立研究页；按板块分批推进，每批同步一份汇总页；已有有效研究页的公司跳过，不重复分析

- 旧页不符合本标准的，单独安排重做，不在原页上混改

## 研究流程（五步）

### 1 立论 · PM 七问 + 商业模式解码

先说清市场错在哪里，再拆谁付钱、收费机制、单位经济与现金转换，找出 2–3 个主导变量；没有变异认知标监控项（stock-analysis）

### 2 取数 · 一手数据 + 核心假设

核实最新财报，保留原始数与标准化桥；关键假设连接量价、利润与现金，每个数字带来源、日期和口径，缺失标 [MISSING]（stock-analysis）

### 3 估值 · 盈利预测 + 三情景交叉验证

预测修正按同年度旧/新快照归因；至少两种适用方法，连接业务驱动与悲观/基准/乐观隐含价，解释方法分歧、敏感性与盈亏比（stock-analysis）

### 4 对抗 · 六专家 + 分歧验证变量

产业、信号、估值、逆向、财报、短线按问题参与，空头逐条回应多头；每处重大分歧列能解决争议的指标、阈值与日期（stock-analysis）

### 5 收口 · 条件化结论 + 证据核对

给综合评级、研究区间与失效条件，核对结论、模型、表格的数字和来源，列验证日历与未决问题；证据不足明确等待证据（stock-analysis）

## 资深 PM 七问

- 什么被错误定价了？（无变异认知 → 监控项或放弃）

- 当前价格反映了什么？

- 什么能证明论点？

- 什么能推翻论点？

- 为什么是现在？

- 什么会改变仓位、评级或目标价？

- 还缺少什么证据？

## 数据纪律

- 每个数字标注来源与截止日期；缺失写 [MISSING]，超过 90 天写 [STALE]，绝不编造，也不用不可靠估计替代

- 每个主张标类型：事实 / 管理层声明 / 市场共识 / 模型输出 / 假设 / 判断

- 财报以公司一手公告为准；第三方数据与公司公告冲突时以公司为准并写明；第三方数据一律标“需核实原文”

- 同一份分析坚持单一口径，不混用多个来源“交叉”凑出一个数

- 历史价格快照只用于叙述；讨论“当前”必须重新取数；盘中价不能称收盘价，要写明行情日期与财报期

- 涉及内幕或未公开信息，明确拒绝

## 各市场财报节奏与看点（使用时核实最新规则）

| 市场 | 披露节奏 | 口径与看点 |
| --- | --- | --- |
| 美股 | 10-Q 按季（财季结束后约 40–45 天），10-K 年报（财年结束后 60–90 天） | GAAP 与非 GAAP 分列；关注股权激励（SBC）；各公司财年不同，财年号不可互换 |
| 港股 | 中报（9 月底前）、年报（次年 3 月底前），不强制发布一季报/三季报 | 只有半年和全年口径；注意港币计价与回购 |
| A 股 | 一季报（4 月底前）、中报（8 月底前）、三季报（10 月底前）、年报（次年 4 月底前） | 看扣非归母净利润、经营现金流/净利润、应收 + 存货占比、商誉、减持与解禁 |

## 口径纪律

| 项目 | 要求 |
| --- | --- |
| TTM PE 与动态 PE | 前者多为 GAAP，后者多为非 GAAP 调整口径，两列不可直接相减；动态 PE、PEG 缺失写 [MISSING] |
| GAAP 与调整后 | 分列，并逐项桥接一次性项目；清洗 ≠ 删除风险 |
| 公司指引与研究假设 | 必须区分；研究者正常化 EPS 不等于公司指引 |
| PEG | 需同口径的可持续未来 EPS 增速；基数效应、周期反弹口径下的 PEG 不是成长股 PEG |
| PB / ROE | 穿透商誉与无形资产看有形净资产；回购或负权益会扭曲 ROE，不适用时如实写“不适用” |
| 倍数分位 | 没有可信的长期历史分位就不宣称“已校准” |

## 研究检查项

### 基本面与盈利质量

- 最新价、52 周高低、TTM/静态 PE、远期 PE、PEG、PB/PS 或 EV/EBIT
- 营收、毛利率、经营利润率、EPS、ROE、ROIC、经营现金流、自由现金流、净杠杆
- 区分正常经营利润与一次性损益、并购、回购、重估收益造成的失真

### 增长、持续时间与护城河

- 增长来自销量、价格、份额、结构、成本杠杆、并购还是周期反转；量价要拆开
- 盈利增长能否至少持续到 2027 年底，并评估更长的复利可能
- 护城河：定价权、转换成本、网络效应、专利监管、规模、渠道、客户黏性、竞争格局
- 写明关键验证指标与可能使论点失效的风险

### AI 只作为可量化的财务变量

- 不是研究主题本身，也不能只描述“公司如何使用 AI”
- 仅当能传导到收入、份额、毛利率、费用率、资本开支或估值持续性时才纳入情景
- 无明确财务传导则标注“AI 为非核心变量”，不作买入理由

### 估值、确定性与盈亏比

- 悲观 / 基准 / 乐观三情景：EPS(FCF) × 合理倍数 = 隐含价，而不是单一目标价
- 预期盈亏比 = 基准上行 ÷ 悲观下行；优先 ≥ 约 2:1，确定性低则要求更高安全边际
- 确定性分高/中/低，并从盈利可见度、订单/复购、现金流、资产负债表、竞争、监管/周期和估值容错解释

## 估值方法

- 以股权价值为最终输出；债务只作为影响股权价值的输入（净债务、资本成本、杠杆、再融资风险）

- 重大判断至少两种独立方法交叉验证：DCF / DDM / 可比公司 / 交易倍数 / NAV / SOTP / 行业专用

- 关键假设（WACC、增长率、折现期、倍数）显式列出；DCF 必须做敏感性矩阵，终值占比 >75% 须警示

- 周期股不用成长股 PEG 框架：低 PE 常是盈利顶部信号；成本周期修复的增速不外推到下一年

- 高股息不等于安全：先看 FCF 覆盖，再看派息率，最后才看股息率

- 区分公司质量与价格：好公司 ≠ 好价格，赔率不足就等待或观察，不因错过而追高

## 常见数据陷阱

| 陷阱 | 典型表现 | 做法 |
| --- | --- | --- |
| TTM PE 失真 | 减值、一次性收益、权益重估、并购整合费用使 PE 异常低或异常高 | 改用正常化 EPS 与动态 PE，并写出桥接 |
| PB 假便宜 | 商誉与无形资产占权益大半，有形净资产为负 | 穿透看有形账面值，商誉覆盖率低则减值未出清 |
| 低基数高增速 | 上年因减值或成本冲击大跌，今年只是修复 | 看核心 EPS 与两年复合增速，不外推 |
| 提价撑收入 | 提价伴随销量下滑 | 看量价拆分，销量连续为负视为透支 |
| 财报期错位 | 第三方季度标签与公司真实财季不符、财年不同 | 一律以公司公告的报告期为准 |
| 目标价滞后 | 卖方目标价尚未随股价下调 | 不作支撑位依据 |
| 事件不是生意 | 赔率来自并购、分拆等交易而非经营 | 单列为事件驱动，确定性按交易成败评估 |

## 对抗检验

- 多头与空头必须真打：空头逐条引用并反驳多头论点；走过场的辩论不如不辩

- 各立场并行、互不知情地独立形成，再由主理人中转；成员之间不直连，避免立场互相传染

- 三位风险分析师（激进/保守/中性）互相点名挑战对方假设，再由风险主管裁决

- 研究主管、风险主管禁止以“双方都有道理”默认持有，必须给明确方向；趋势判断不许说“趋势混合”

- 需要多视角时用专家团圆桌：产业、信号、估值、逆向、财报、短线各说各的，报告固定四模块——结论卡、子专家观点、深度思考、后续关注

## 固定结论格式

- **公司简介**：先用几句话说清这是一家什么公司：做什么、靠什么赚钱、行业位置、最近一次大事件

- **业务分布**：按分部/产品/地区拆收入或利润占比，指出利润集中在哪一块

- **优势与缺点**：各 3 条左右，对应护城河、成本结构、财务与治理短板，每条有事实支撑

- **行业趋势**：行业供需、周期位置、政策与技术变量，写明对这家公司是顺风还是逆风及传导路径

- **评级**：买入 / 持有 / 观察 / 回避，并说明核心理由；证据不足写“等待证据”，不硬凑结论

- **合理买入区**：价格与安全边际匹配时分批买入，不因短期热点追高；区间由“情景 EPS × 倍数”反推并写明推导

- **确认加仓**：价格突破与下一期财报、订单、利润率、现金流或指引共同验证后才加仓

- **减仓 / 止盈**：达到或接近乐观情景估值、盈利预期不再改善、或赔率变差时分批处理

- **失效条件**：可观察、可量化、有时间约束；发生后重新评估，而非机械补仓

- **仓位原则**：高确定性 + 高盈亏比优先；高增长但低确定性只做较小、事件驱动型仓位

## 最终返回标准（0–14 模块）

| 编号 | 模块 | 必含内容 | 最低要求 |
| --- | --- | --- | --- |
| 0 | 头部信息 | 公司 / 代码 / 市场；研究日期；价格锚点（收盘或盘中要写明）；财报期；主要数据来源 | 一行写完，缺任何一项都要标 [MISSING] |
| 1 | 公司简介 | 做什么的、靠什么赚钱、在行业里的位置；最近一次大事件（并购、分拆、减值、CEO 更替等） | 3–5 句，先让读者知道这是一家什么公司 |
| 2 | 业务分布 | 按分部/产品/地区拆收入与利润贡献；说明客户、收费机制、单位经济与现金转换，画出业务驱动树 | 按实际披露列主要分部并与合并口径勾稽；选出 2–3 个主导变量，取不到的写 [MISSING] |
| 3 | 优势与缺点 | 优势与缺点各 3 条左右，对应护城河、成本结构、财务与治理短板 | 每条要有事实或数字支撑，不写空话 |
| 4 | 行业趋势 | 所处行业的供需、周期位置、政策与技术变量；对这家公司是顺风还是逆风 | 3–4 条，区分“事实”和“判断”，并说明对本公司的传导路径 |
| 5 | 结论卡 | 评级；一句话结论；预期盈亏比；确定性（高/中/低）；增长可持续期限（到 2027 年底？更长？） | 3–5 句，必须给方向，不写“两边都有道理” |
| 6 | 关键指标 | 估值：TTM PE / 动态 PE / PEG / PB 或 EV/EBIT；增长：收入、EPS、FCF；质量：毛利率、ROE/ROIC、现金流/净利润；杠杆 | 每项带口径（GAAP/调整后、TTM/指引）与日期 |
| 7 | 增长与护城河 | 增长来源（量/价/份额/结构/并购/周期）、持续期限、竞争与 AI 传导；核心假设及敏感性，按需核市场空间与周期 | 至少 3 条有数字或可观察证据；主导假设给定义、预测区间、阈值与验证日期 |
| 8 | 三情景估值表 | 悲观 / 基准 / 乐观：驱动假设、盈利或现金流、估值输入、隐含价、上下行与证伪；预测修正/每股价值桥、方法分歧与盈亏比 | 计算可复现；概率与期望收益注明研究假设；无可比旧快照不得称预测上修/下修 |
| 9 | 结论与买入纪律 | 评级理由；合理买入区；确认加仓条件；减仓 / 止盈条件；失效条件；仓位原则 | 价位必须写明由“情景 EPS × 倍数”反推，并标为条件化研究区间 |
| 10 | 风险与证伪 | 3–5 条可观察、可量化、有时间约束的证伪条件；最大的一个反证要单独点名 | 不能只写“行业竞争加剧”这类泛泛表述 |
| 11 | 多空交锋 | 多头最强论点；空头最强论点；裁决及理由 | 空头必须逐条回应多头；缺则写“未做对抗检验” |
| 12 | 口径与陷阱 | 一手/二手来源；第三方冲突及处理；被清洗的一次性项目；本页所有 [MISSING] 清单 | 冲突以公司一手公告为准并写明 |
| 13 | 后续验证日历 | 下次财报日期；关键变量与验证阈值；重评触发条件 | 有日期的写日期，没有的写“待公告” |
| 14 | 免责声明 | 本报告仅供研究参考，不构成个人投资建议 | 每份输出结尾必带 |

## 项目个人仓位原则（按用户选择适用）

- 主动层单一标的上限：占总资产 4%~5%；分散在 4~5 个不相关机会，禁止一把梭

- 左侧建仓不超过 50%，仅依逻辑证伪平仓、不设机械价格止损；右侧确认后再打满，并启动成本 −10% 减半、−15% 全部止损

- 主动资金独立管理，不挪用被动底仓与备用金；连续 3 笔触碰止损，强制停止主动交易 3 周

## 红线

- 不编造数据；查不到写 [MISSING]，第三方冲突写明并以一手为准

- 不把低 PE、高股息、高增速单独当作买入理由

- 不把研究区间、情景价当作目标价或交易指令；所有价位是条件化的研究假设

- 不使用指令性措辞（“建议买入/卖出/X 成仓”），除非用户明确要求交易提案

- 不拿内幕或未公开信息；每份输出结尾保留免责声明
