# AI 应用

整理日期：2026-10-07。先读 [观察池规则](index.md)。

大模型落到办公、开发、营销、内容、金融医疗教育与终端硬件的应用层：收入来自订阅、用量与广告，成败取决于付费转化与算力成本。算力与模型见「人工智能」赛道。

阶段判断：应用层处于从试点到规模付费的过渡：头部软件与平台已有可见收入，多数应用的付费、续费与毛利率仍待验证。

收益传导：潜在传导：有效使用与付费 → 订阅、用量或广告收入 → 扣除算力、人力与获客成本后的利润。应用层的壁垒来自数据、分发、工作流嵌入与转换成本；模型能力趋同时，单纯调用大模型接口的应用容易被替代。
