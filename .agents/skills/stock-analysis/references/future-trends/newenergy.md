# 新能源

整理日期：2026-10-07。先读 [观察池规则](index.md)。

锂电、光伏、储能、电网与核电。需求持续增长，但产能周期会压缩利润。

阶段判断：成熟发电、锂电与电网业务和新电池/氢能/反应堆研发并存，不能用同一阶段概括。

收益传导：潜在传导：终端有效需求 → 订单/付费使用 → 收入 → 扣除成本、研发与再投资后的现金流。电气化提高电网、储能与电池的需求。已过去的光伏与锂电告诉我们：需求增长不保证利润，要看谁在产能出清后仍有成本优势。

书中方法：第29章（周期）；第31章 31.7
