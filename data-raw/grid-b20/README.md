页面：`/note/lab/grid-trading/detail/?code=159593`，K 线下方“成交额加权趋势”之后的副图，显示开关“B20 申赎篮子宽度”。
目前只对 159593（平安中证A50ETF，目标指数 930050）显示；其他 ETF 没有经过核验的 B20，不显示。

## 口径

沿用 gupiaoWS 研究「ETF 历史申赎篮子成分宽度」：`industry_breadth_audit/protocol_IB.md` §1–4、`protocol_amendments_IB.md` A3/A3b、
`b20_top_expansion/protocol_B20TX.md` §4。解析器移植自 `own_etf_audit/scripts/breadth_data.py`，复权与三态判定移植自 `lib_ib.stock / tri`。

- **篮子**：t 日 = 深交所 `ETF159593{yyyymmdd}.txt`。日期、基金代码 159593、目标指数 930050 必须相符；解析成分数 + 现金占位 159900 = 申明只数。
  N = 除 159900 外的全部证券，股数为 0 或“必须”现金替代的仍算。当日无清单（404）→ 当日留空，不前填，不用其他日（尤其不用今天）的篮子；请求失败或核验不通过 → 本次更新失败、不写盘。
- **价格**：腾讯不复权日线 × 比例事件链（后复权方向）。事件只采用腾讯日线内嵌分红送转与东财“实施分配”两源一致的；不一致 → 未核实，
  窗口 (t−20, t] 跨越它的成员当天未知。东财空表需巨潮“权益分派”类公告无实施公告才判无事件。
  不使用腾讯 `hfqday` / `qfqday` 做价格（已核实是加法口径，如 600519 的 qfq = 不复权 − 常数）。
- **第三源旁证（本页新增）**：腾讯前复权大体是加法口径但不严格（除权日跳变与派现常差 1%–3%，送转之前的阶段也不是简单仿射）。
  所以只在非事件日核对：相邻两天的涨跌须与不复权一致，出现明显跳变（> 0.1% 价）的日子并入未核实事件（可能是两源都没记的配股等）；
  除权日只报告量级偏差、不改判；之后还有送转的阶段不核对。
- **B20**：成员 adj_t 严格大于此前 20 个 A 股交易日（沪深300 日线日期，不含 t）adj 均值记“站上”；t 与这 20 日任一缺 K 线记未知，不填充停牌。
  “严格大于”用 `math.fsum` 求均值并留 1e-9 相对容差：十进制价格的均值恰好等于当日价时（如紫金矿业 2024-12-24 收 15.63 = 前 20 日均价），
  浮点求和会差 1e-15 而误判站上；真实最小价差约 1e-7 相对，仍可区分。
  B20 = 站上 ÷ 有效（真 + 假）；有效 ÷ 篮子 < 95% 留空，保留计数与原因。
- **可得性门槛（原研究严格版）**：PCF 的 Last-Modified（北京时间，比较到秒）晚于当日 09:00:00 或缺失 → 当日 B20 留空（原因 `lm_late` / `lm_missing`）。
  原研究按分钟比较（09:00:59 仍算有效），这里更严；现有数据里没有落在 09:00:00–09:00:59 的日子，两者结果相同。
  每份历史 PCF 都拿到了 Last-Modified，故沿用；但它只是服务器元数据，不等于清单的实际发布时间，不能证明历史上何时披露。
- **审计层级**：这是按原口径的再计算，没有经过原研究的冻结哈希、截断因果、BaoStock 对账与独立 QC；原研究的“保守 negsearch 情形”未做。
- 只作收盘观察：不参与网格回测、买卖信号、成交额加权趋势。

## 更新

```sh
npm run grid-b20:update   # 收盘后（北京时间 16:00 之后）运行；16:00 前不计当天
npm run grid-b20:test
```

写盘保护（页面数据与溯源清单总是同一次运行一起写出）：

| 情形 | 结果 | 退出码 |
|---|---|---|
| 任一来源 403/429（立即停止该来源） | 两份文件都不动 | 2 |
| 拉取失败（重试后仍网络错误、接口错误、空响应）或 PCF sha256 不符 / 核验不通过 | 两份文件都不动 | 2 |
| 过去有数的日期被重算成缺失、整行消失或截止日后退（疑似数据源静默缺数） | 两份文件都不动；人工确认后可加 `--allow-regress` | 3 |
| 新交易日成员缺数、覆盖不足 | 照实写入（原因 `coverage`） | 0 |
| 过去有数的日期取值变化（如数据源修订） | 写入，并在日志列出 | 0 |
| 页面数据除生成时间外无变化 | 不写盘，不产生提交 | 0 |

`.github/workflows/grid-b20.yml` 在交易日北京时间 17:20 跑同一命令；命令非 0 时不提交。提交后推送若因其他定时任务刚推过而 non-fast-forward，
会 fetch + rebase 后再推一次，变基冲突则放弃本次。PCF 只抓清单里没有的新日期（最近 5 个交易日的 404 会重试），
已有日期在没有原文件时使用清单里核验过的成员版本；个股日线与分红表每次重取。请求单线程，PCF 1s、腾讯 1.2s、东财 1.5s、巨潮 3s 间隔；
任何来源返回 403/429 立即停止该来源，不重试、不绕过。
