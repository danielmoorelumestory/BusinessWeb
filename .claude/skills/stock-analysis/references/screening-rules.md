# 程序化研究页规则（历史补全批）

来源：项目 ResearchNotes.tsx「研究方法 · 适用于所有公司」中的程序化规则表。用于筛选与排序，定性只做简述，不含公司特有催化与风险，不等同于逐家深度研究。本入口的公司级验证要求优先。

| 项目 | 历史规则与限制 |
| --- | --- |
| 数据源 | 美股：东方财富单季财务 + 新浪日线；A 股：同花顺财务摘要（累计还原单季）+ 新浪日线 + 中证/巨潮行业分类。成分股使用 2026-09-30 标普500公开名单、中证500成分，使用前重核成员。 |
| TTM | 美股最近四个单季稀释 GAAP EPS 之和；A 股 TTM 归母净利 / 最新隐含股本。公司级研究须核实际股份变化。 |
| 拆股 / 除权 | 美股依隐含股本持续阶跃与价格跳变折算；A 股按发布财报后价格跳变 ≥1.28 倍折算。仅检测线索，须核实施公告。 |
| 归一化 | 四季中一季净利率明显偏离其余三季紧密区间时，用其余三季中位净利率替换；金融、地产不做。保留前后 EPS；不能代替一次性项桥接。 |
| 基准 | EPS = 归一化 TTM × (1+g)；g = 最新季营收同比 ×0.7，限 −5%~+20%；倍数为现倍数与板块中位的中点、不高于现倍数1.25倍、限7–40。只作筛选假设，营收增速不得直接认证EPS增长。 |
| 悲观 / 乐观 | 悲观 EPS × (1−h)，h为防御15%、一般20%、周期25–30%；倍数 min(现倍数, 0.6×板块中位)、下限5。乐观 EPS × (1+2g+8%)，倍数1.15×基准。 |
| 买入区 | 历史公式 P=(Base+2Bear)/3，取±5%；深度研究须重新检验情景与安全边际。 |
| 评级 | 历史筛选 R≥2优先关注、1–2条件关注、其余观察，TTM亏损回避；营收同比波动>40–50%、股本变动>25%、EPS符号翻转、Bear≥P时封顶观察；金融及非金融负债率>80%最高条件关注。均非深度认证结论。 |
| 排除项 | REIT不用EPS情景（需FFO），亏损公司不用EPS情景，缺失标[MISSING]。 |
| 局限 | 高PE偏严、低PE偏宽；一次性项可能误判或漏判；未取得FCF、分部占比、一致预期及下跌原因。价差比未含情景概率、兑现时间或分红。 |
