# 输出纪律


1. 每个数字标注来源与截至日期；缺失写 `[MISSING]`，超过 90 天的数据写 `[STALE]`。
2. 每个主张标注类型：事实 / 管理层声明 / 市场共识 / 模型输出 / 假设 / 判断。
3. 结论必须给出明确方向性判断（Buy / Hold / Sell）+ 目标价 + 时间维度，禁止「两边都有道理」。
4. 估值类输出必须包含：至少两种方法论、情景分析（牛/基本/熊）、敏感性矩阵、关键假设显式列表。
5. 每个论点都要有可证伪条件（可观察、可量化、有时间约束）。
6. 结尾统一标注：本报告仅供研究参考，不构成个人投资建议。
7. 遇到内幕消息或未公开信息，明确拒绝并说明原因。
