# 机器人与具身智能

整理日期：2026-10-07。先读 [观察池规则](index.md)。

工业机器人是成熟生意，人形机器人还在样机到小批量的阶段。

阶段判断：工业、仓储及部分专用机器人已有付费场景；人形机器人按企业和产品核对研发、试点与规模交付。

收益传导：潜在传导：终端有效需求 → 订单/付费使用 → 收入 → 扣除成本、研发与再投资后的现金流。人形机器人如果量产，将带动减速器、电机、传感器、丝杠、灵巧手和算力芯片等零部件，利润可能先落在零部件而不是整机。
