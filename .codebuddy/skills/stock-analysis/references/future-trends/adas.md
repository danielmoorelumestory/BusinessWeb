# 智能驾驶

整理日期：2026-10-07。先读 [观察池规则](index.md)。

从辅助驾驶到高阶自动驾驶和 Robotaxi，技术、法规和商业模式要同时成立。

阶段判断：辅助驾驶量产与无人驾驶运营并存；按具体地区、车型与许可核对，不用 L2 交付代替 L4 证明。

收益传导：潜在传导：终端有效需求 → 订单/付费使用 → 收入 → 扣除成本、研发与再投资后的现金流。辅助驾驶搭载率提高，带动传感器、计算芯片、域控制器与软件订阅；无人出行如果单位经济成立，将改变出行服务的成本结构。

书中方法：第31章 31.5
