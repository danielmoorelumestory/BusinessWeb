# 人工智能（AI）

整理日期：2026-10-07。先读 [观察池规则](index.md)。

覆盖算力、存储、互联、电力、数据、模型与应用；逐环节研究订单、付费与现金回收。

阶段判断：硬件、云平台与应用的商业化程度不同；按产品收入、增量利润和现金回收逐项判断。

收益传导：算力、数据和应用的有效付费需求分别带动硬件、基础设施与软件订单；谁保留利润取决于定价权、成本、竞争和客户回款，不能预设全部利润集中在某一层。
