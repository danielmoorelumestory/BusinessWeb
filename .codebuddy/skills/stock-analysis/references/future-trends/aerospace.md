# 航空航天

整理日期：2026-10-07。先读 [观察池规则](index.md)。

包括低空经济、商业航天、商用大飞机与航空发动机，航空公司则属于周期股。

阶段判断：卫星通信、航空运输与部分飞行器已有商业业务；新火箭和 eVTOL 按型号认证、运营许可与经济性判断。

收益传导：潜在传导：终端有效需求 → 订单/付费使用 → 收入 → 扣除成本、研发与再投资后的现金流。低空看适航与运营规则；商业航天看发射成本下降和卫星业务收入；大飞机与发动机看产能与供应链，订单周期长、能见度高但交付节奏受限。

书中方法：第31章 31.7；第29章（周期）；附录D

## 风险与证伪线索

- 认证与审批周期拉长。
- 主题估值远快于收入。
- 安全事故会让监管收紧。
- 军工订单与采购节奏存在不确定性。
