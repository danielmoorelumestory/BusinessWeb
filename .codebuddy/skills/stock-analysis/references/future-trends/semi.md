# 半导体与先进制造

整理日期：2026-10-07。先读 [观察池规则](index.md)。

AI、汽车与机器人共同依赖的底层环节；周期强，国产替代是中国市场的主线。

阶段判断：成熟工艺与先进节点、工具与制造处于不同竞争阶段；以客户认证、订单和良率验证替代进度。

收益传导：潜在传导：终端有效需求 → 订单/付费使用 → 收入 → 扣除成本、研发与再投资后的现金流。所有上面的赛道都要用到芯片，所以半导体属于“卖铲子”的一环。但行业有强周期，库存与资本开支会让利润大起大落。

书中方法：第29章（周期）；第31章；产业格局页的半导体产业链
