# 新材料

整理日期：2026-10-07。先读 [观察池规则](index.md)。

先收窄到一个具体材料再研究：稀土永磁、碳纤维、半导体材料、关键金属。

阶段判断：已量产产品与新牌号认证并存；材料性能、规模成本和客户转换分别核验。

收益传导：潜在传导：终端有效需求 → 订单/付费使用 → 收入 → 扣除成本、研发与再投资后的现金流。新材料多是上游的壁垒型生意：认证周期长、一旦导入替换成本高；但研发投入大，现金流与融资能力要撑得住。
