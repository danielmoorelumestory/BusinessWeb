# Live Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 Live 站点交付可持续导入 Markdown 的博客，支持正式浏览、阅读和通向现有书与工具的转化入口。

**Architecture:** `manifest.json` 是唯一公开目录；本地导入脚本只处理明确登记的文章。前端静态读取元数据、按需加载 Markdown；同一安全渲染函数供文章页和构建时预渲染使用。现有主导航、搜索、SEO、sitemap 与 Pages 构建流程接入 `/blog`。

**Tech Stack:** React 18、React Router 6、TypeScript、Vite、Marked（已有依赖）、Node.js、Vitest。

**Spec:** `docs/superpowers/specs/2026-10-13-blog-design.md`

## Global Constraints

- 源仓库 `danielmoorelumestory/gupiaoWS` 的 `master` 当前只有书稿与审稿记录；只发布清单中 `status: "published"` 的文件，不能自动把整本书或修订文件公开。
- 文章发布日期必须来自清单中的 `publishedAt`；文件时间与源 Git 提交时间不得冒充发布日期。
- 保持 Live 的暖白底、深灰字、绿色主色和现有衬线标题；手机、键盘和屏幕阅读器均可使用。
- 文章末尾只链接已经存在的书、工具和栏目；不要添加无法完成的支付、订阅或联系按钮。
- 当前工作区的候选池文件已有未提交改动；每次提交只暂存本任务指定的博客文件。

## Review Focus

- 源路径 `../` 逃出源目录：导入必须拒绝，且不得复制目录外文件；Task 1 测试。
- 清单把审稿文件误标记为草稿或未登记：公开目录和站点地图都不能出现；Task 1、2、5 测试。
- Markdown 含 `<script>`、`javascript:` 或带事件属性的 HTML：浏览器与预渲染输出都只显示安全内容；Task 2、5 测试。
- 中文重复标题及含图片的相对路径：目录锚点唯一，图片在文章页和静态输出均可访问；Task 1、2、4 测试。
- 搜索、分类组合后无结果，或首次没有文章：提供可恢复的空状态和真实阅读入口；Task 3 测试。

### Task 1: 显式发布清单与本地导入

**Files:** Create `src/content/blog/manifest.json`, `scripts/import-blog.mjs`, `scripts/import-blog.test.mjs`; modify `package.json` to add `blog:import`.

**Interfaces:** `manifest.json` is an array of `{ slug, title, summary, category, tags, publishedAt, updatedAt?, file, sourceFile?, sourceUrl?, status }`; `file` points to `src/content/blog/posts/<slug>.md`. Export `importBlog({ sourceRoot, targetRoot, manifestPath }): Promise<{ articles: number; assets: number }>` from the Node script; CLI takes `--source <local checkout>`. The import processes only published entries with `sourceFile`; entries without it are maintained locally.

- [ ] **Step 3: Implement importer and CLI.** Validate the manifest before copying; constrain resolved source and destination paths; rewrite copied image links to `${BASE_URL}blog/assets/<slug>/...` through a base-independent `/blog/assets/...` path stored in Markdown and resolved by the renderer. - [ ] **Step 4: Run `node --test scripts/import-blog.test.mjs`.** Expect all importer cases to pass.
