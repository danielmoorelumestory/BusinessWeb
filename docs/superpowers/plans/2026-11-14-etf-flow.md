# ETF 资金净流入页接入 BusinessWeb 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 BusinessWeb 站内新增 `/etf-flow` 页，展示全A/宽基 ETF 日度净流入（红绿柱）+ 上证指数叠加，由 Node 快照脚本每日经 GitHub Actions 产出 `public/data/etf-flow.json` 驱动。

**Architecture:** 复用站点现有范式：`scripts/lib/*.mjs` 纯函数 + `scripts/*-snapshot.mjs` 编排 → `writeJsonIfChanged` 写 `public/data`、缓存入 `data-raw` → GitHub Actions cron 提交并触发 `pages.yml` 部署；前端 React Router 页 + 内联 SVG 自绘图表，无新增图表依赖。

**Tech Stack:** Node 24+（原生 fetch，`fetchImpl` 注入可测）、vitest、React + react-router-dom、@testing-library/react + jsdom。

**Spec:** `docs/superpowers/specs/2026-11-14-etf-flow-design.md`（业务口径承接 `gupiaoWS` 仓库 `output/同花顺ETF资金/设计-ETF资金净流入页.md` 已评审版）

## Global Constraints

- Node 24+；一切网络调用经可注入的 `fetchImpl` 参数，默认全局 `fetch`。
- **不引入图表库依赖**（echarts/recharts/d3 一律不加）；图表用内联 SVG，参照 `src/components/pulse/ChinaMarketCharts.tsx`。
- 份额单位换算：沪 `TOT_VOL`、深 `dqgm` 均为万份，×10000 = 份。展示亿元 = 元 / 1e8。
- 柱色：红 `--up` = 净流入(正)、绿 `--down` = 净流出(负)，沿用站点颜色变量；脉搏/监控页约定不借用 `--up/--down` 的规则不适用于本资金页（本页就是涨跌语义）。
- 乘数用**市价**（`fetchEtfUniverse` 的 `price`），非 NAV。
- 产出用 `writeJsonIfChanged`；份额基准与名单缓存提交进 `data-raw/etf-flow/`。
- 代码注释与界面文案用简体中文。
- 残缺日守卫：沪市份额为空即整体跳过不落库、不计算。

## Review Focus

- **交易所接口在 CI 返回空/限频(429)/超时**：沪空 → 整体跳过不写；深空 → 仅深市缺，不毒化沪市前值，不产生全A骤降假信号。（Task 2 测试覆盖沪空跳过、深空降级）
- **份额字段/单位漂移**（`TOT_VOL`/`dqgm` 改名或单位变）：解析得到 0 条或数量级突变时不静默产出。（Task 1 测试：空/异常响应解析为空并可被上层识别）
- **折算/拆分阈值边界**：`|Δ|/前值` 恰在 0.5 附近。（Task 1 测试：0.49 计入、0.51 剔除）
- **市价为 0 或缺失**（停牌/新上市当日有份额无价）：跳过该只，不产生 NaN/Infinity。（Task 1 测试：price=null/0 跳过）
- **前端 `etf-flow.json` 为空或字段缺**（首次部署、series 为空）：页面不崩，显示占位。（Task 4 测试：空数据渲染占位不抛错）
