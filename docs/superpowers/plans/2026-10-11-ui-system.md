# 统一组件层与移动端适配 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在用页面统一宽度、语义与视觉组件，手机上点得准、表格看得全，并用棘轮测试防回退。

**Architecture:** `src/styles/ui.css` 提供共享类与尺寸 token；`src/components/ui/` 提供薄组件（Page / PageToolbar / Card / Callout / Stat / Badge / TableWrap / EmptyState）；页面逐批把根节点和布局内联样式换成这些类；`inlineStyleRatchet.test.ts` 锁住每个文件的内联样式与硬编码颜色数。

**Tech Stack:** React 18 + TS + Vitest + Testing Library；纯 CSS。

**Spec:** `docs/superpowers/specs/2026-10-11-ui-system-design.md`

## Global Constraints

- 只加尺寸 token，不加颜色；颜色只用 `src/index.css` 已有 token。
- 不改业务逻辑、数据、路由；不删现有测试（断言依赖旧内联样式时改写断言，保留意图）。
- 页面名由面包屑显示，h1 用 `PageTitle` 视觉隐藏（沿用现状）。
- 在用页面统一 1100px（`--page-max`），阅读页 760px（`--page-reading`）。
- 数据驱动的内联样式（热力图色、进度宽度、计算出的涨跌色）允许保留。
- 已舍弃页面与 `components/monitor/*` 只换外壳。
- 测试：`npm test -- run <path>`；全量 `npm test -- run`、`npm run typecheck`、`npm run build`。

## Review Focus

1. 页面换成 `<Page>` 后，原来依赖根节点 `minHeight: 100vh` / 背景色的页面底部出现色差或塌陷 → `.page` 自带 `min-height` 与透明背景，body 背景统一。（Task 2 截图验收）
2. `.page-tabs` 吸顶在 `<Page>` 内部时被 `.container` 的边距挤窄，吸顶条不再通栏 → `.page > .page-tabs` 用负边距通栏。（Task 1 CSS + Task 2 截图）
3. 表格首列吸附时背景透明导致滚动内容透出 → 吸附单元格设 `background: var(--bg-card)`。（Task 1 CSS）
4. `pointer: coarse` 放大按钮后工具栏在 390 宽下换行挤压 → 工具栏 `flex-wrap`，说明文字占满一行。（Task 7 验收）
5. 棘轮测试对「减少」不失败但不更新基线，导致基线漂移 → 测试在低于基线时打印提示，最后一个任务统一收紧基线。（Task 3、Task 8）
