# 创新药

整理日期：2026-10-07。先读 [观察池规则](index.md)。

成功率低、一旦成功回报大；中国创新药近年的变化是对外授权与出海。

阶段判断：销售中药物、注册阶段、临床管线及科研服务并存；按产品和适应症核验。

收益传导：潜在传导：终端有效需求 → 订单/付费使用 → 收入 → 扣除成本、研发与再投资后的现金流。受益方在研发、临床、商业化三个环节分化：有已上市产品和现金流的公司风险较低，纯管线公司取决于临床结果与现金储备。
