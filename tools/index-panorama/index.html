导入 CSV（仅本次会话）

导入的数据只保存在当前页面内存中，刷新或关闭页面即丢失，不会修改原始数据文件。 同代码按日期合并：导入值覆盖同日已有值，空单元格保持原值。

PE / PB 特殊规则：估值口径不跨来源拼接。若 CSV 为某代码提供了任一 PE（或 PB）值， 该指数的整列 PE（或 PB）改为只用本次 CSV 提供的日期观测，原来源该列的其余数据本次会话不再使用， 分位等统计只基于导入值；PB 原本为空时即直接补全。

列：code,name,category,date,price,chg,pe,pb,dy,mcap,amt,turn,eps,roe,bps,volume。 code / name / date 必填，每行至少一个有效数字；日期格式 YYYY-MM-DD； 单位同数据契约（chg/dy/turn/roe 为百分数，mcap/amt 为亿元，volume 为股）。 任一行有错误则整份文件不导入。
