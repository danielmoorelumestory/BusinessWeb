# 上证指数 PE 15.93（原站）与 14.64（本地）差异，及上证 ROE 缺失专项

2026-11-15，domestic provider owner（Claude）。只用本地已验证的 raw 缓存、公开 HTTP 和原站公开 JS（`/tmp/lishenqi-panorama.js`，只读）。本次我没有操作 Chrome（避免与 manager 的会话冲突），没有调用原站数据接口，也没有改数据管线、数据值或 bundle。

## 结论

1. **本地字段映射核对通过。** 本地 14.64 就是中证官网 `indexCsiDsPe` 返回的 2026-11-11 上证指数 `peg`，官网列名「滚动市盈率」（英文 i18n 键 PETTM）。中证另一个接口「每日指数信息-指数估值」同日的 `peg` 也是 14.64，两者一致。**映射核对通过只说明本地如实取了中证这一列，不代表 14.64 和原站 15.93 应该相同，也不代表哪一方是对的。**
2. **15.93 和中证公开的三列 PE 在任何已缓存日期都对不上：**
   - 静态口径最接近：`indicator.xls` 的 PE1（总股本）在 2026-11-11 为 15.82，PE2（计算用股本）为 15.80，indexValuation 的 `pe` 为 15.82。
   - 近 20 个交易日（10-15 到 11-11）里，PE1/PE2 的最大值是 15.88（11-04），从未出现 15.93。
   - 2026-11-12、11-13 上证收盘为 3655.83 和 3634.35，比 11-11 的 3680.64 低 0.67% 和 1.26%。**如果盈利基数不变**，这两天任何一列 PE 都会更低（PE1 约 15.6，peg 约 14.45）。
   - 但本次缓存只到 11-11，**无法排除 11-12/11-13 盈利基数（或成分、股本）发生更新**。所以「日期差能否解释 15.93」目前无法判定，不能用来排除原站与中证同口径的可能。
3. **15.93 的来源目前无法用公开信息确认：**
   - 原站 JS 中所有估值都通过 `Cloud.call('lsqSiteAdmin', {action:'ixSeries'|'ixPanel'})` 从站方云函数获取（第 11-14、43-50 行），**前端没有披露上游数据源，也没有说明 PE 是 TTM、静态还是什么加权方式**。
   - 原站把恒生指数代码写成 `HSI.HI`（第 104-105 行），这是 Choice/Wind 一类终端的代码习惯。ROUND2.md 第 60 行也把原站数据称为「Choice 数据」。这只能说明数据可能来自商业终端，**无法确认具体是哪一列**。
   - 我没有调用该云函数，也没有读取原站登录后的页面，因此 15.93 的字段名、日期和口径都**未核实**。
4. **结论只能是「原站 15.93 的来源和口径未核实」，不能断定它是另一口径。** 不建议为凑数修改：不能用 PE1 或其他列替换 14.64 后宣称和原站一致。

- 原站 8.2% 的直接来源、计算定义和日期都**未核实**。本地不用 PB/PE 推算 ROE。
- **结论：上证 ROE 仍未补齐。**
