## 3. 具体差异与改进

**改前**（截图见 `reports/screenshots/home-desktop.png`、`detail-mobile-initial.png`）的问题：
- 顶栏为深蓝整栏；
- 侧栏是 260px 纵向列表；
- 首页各区块为通栏 `section`；
- 详情页依次是大标题、两组分段按钮、2.2:1 的主卡和温度计，主卡上方堆了 8 格统计卡，盈利和成交热度与回撤同排；
- 来源表直接展开在页面中。

**第一轮**（按公开骨架）：
- 重写 `styles.css` 与 `detail.css` 的配色 token，取参考的 brand `#123f6d`、brand2 `#1d5c9e`、gold `#a8741a`、up `#c0392b`、down `#0f6e56`；
- 侧栏改为分组卡 + chip；
- 首页加入「横向比较」「组合视角」标题，并把风格轮动和跨境对照并排；
- 详情页按 PANO_SHELL 的顺序重排，区间按钮放进大卡，8 格统计改成 KPI 行加底部一行，新增 4 张小卡与迷你线（只用真实观测，少于 2 个或单期时不画）。

**第二轮**（按 Codex 实看反馈与 Chrome 自检）：
1. 顶栏改为白色全站栏。
2. 主图改为金色曲线。背景分三区：低于 20% 分位为绿，20–80% 为淡黄，高于 80% 为淡红。分界是所选区间真实样本的分位，样本不足时不画。
3. 「估值与盈利」改为 PE（左轴）对 EPS（右轴）。EPS 未取得时只画 PE，并写明「数据源未提供 EPS 序列……不从点位或 PE 反推盈利」。
4. 「成交热度」改为成交额柱加收盘点位线（双轴）。
5. 小卡里的长来源文本只保留来源名，完整口径放在 title 和页尾覆盖表中，避免撑高卡片。
6. 指数栏压成一行。数据提示改为「数据提示 N 条 ↓」按钮，点击后展开并跳到页尾列表；没用 `#锚点`，避免与 hash 路由冲突。
7. 跨境对照原先在半宽卡里横向截断，改为不设最小宽度、长文案换行。
8. 窄屏首页的表头里有一个 `visually-hidden` 的绝对定位 span，它跑出了滚动容器，把布局视口撑到 780px。给 `.table-wrap` 和 `.pd-table-wrap` 加 `position:relative` 后修复，现在 `innerWidth = scrollWidth = 390`。

## 3b. 二审修正（Codex 视觉复核后，同一 1440 宽度对照）

1. **提示去重**。原来有三处：页顶黄色大横幅、指数栏「数据提示」、「查看数据提示」。现在每页只有一个紧凑入口：
   - 首页：页头小字「数据说明 3 条 ↓」；
   - 详情：指数栏小按钮「数据提示 N 条 ↓」。

   详情内容统一折叠在页尾：数据包级说明在 `#pageNotes`，单只指数提示在「来源与覆盖」卡内。大横幅只保留给数据包缺失、模块缺失、本地存储不可用这几种真实错误。
2. **指数栏压成单行，首屏密度对齐**。顺序为：名称、代码 · 分类 · 成分股（小字，单行截断；说明文字放 title）、点位涨跌、提示入口，最右是收盘日。在 1440 宽度下 36 页实测：
   - 指数栏高度全部为 **52px**（原站约 52px）；
   - 主图卡顶全部在页面 y=**227**，加上 Chrome 界面约 347，原站约 360。

   截图：`detail-000001-desktop-top.png`。
3. **估值温度计改成原站形态**：
   - 结构：市盈率大字（34px）+ 冷热标签 + 渐变条和定位针（role=meter）+ 一行三格（区间分位 / 市净率百分位 / 较上周）+「历史位置」一句话；市净率和股息率两行收进「次要字段」折叠。
   - 历史位置句只按真实分位分三段描述：低于 20% / 20–80% / 高于 80%。措辞示例：「市盈率 14.64 倍（2026-11-11），不低于近10年 2427 个观测中的 64.11%，处于历史中段……仅描述自身历史位置」。不含买卖建议。
   - 单期或缺失时：不显示分位、渐变条、冷热和结论，改写「样本不足 / 没有市盈率观测，不作历史位置描述」。
   - 较上周：最新观测往前 7–13 天内有真实观测才计算，并注明对比日期。36 页中 32 页有值；国证2000（单期）和 3 只美股（单期或无 PE）显示「未取得」。
   - 新增 3 个回归测试：日频算出较上周、月频未取得、单期 / 无 PE 不给结论。截图：`detail-000001-desktop-thermo.png`、`detail-000001-mobile-thermo.png`。
4. **侧栏「全局坐标」改为 2×2 卡片**：名称 + 角色标签（统筹全局 / 深市权重 / 成长风向 / 硬科技）+ 一句看点 + 点位 + 涨跌；当前页卡片为金色实底。其余分组仍用 chip。截图：`detail-000001-desktop-top.png` 左栏、`home-mobile-nav.png`。
5. **报告更正**：ROE 实为 22/36 有值，见第 7 节。

## 4. 数据真实性（逻辑未改，测试全过）

以下逻辑全部保留：
- 单期或样本不足 2 个时，不显示分位、20/80 带、三区背景和冷热，也不画主图和迷你线；
- 明确标出样本覆盖期，频率以来源声明为准；
- 缺失字段给出简短原因，完整原因可展开；
- mcap 按 `marketCapBasis` 动态显示「自由流通市值 / 总市值 / 市值（口径未注明）」，非 total 口径页面不出现「总市值」；
- 港股成交额小卡新增「原币换算：European Central Bank…参考汇率，只用同日汇率，缺日不前填」，并链接到汇率来源；
- CSV 导入、PE/PB 整列替换、稀疏数据逻辑未改。

## 7. 仍存在的差异（逐项，均未声称已与原站逐页一致）

以下对照依据：原站公开的页面骨架和样式、Codex 在已登录 Chrome 中的实看描述、本地 1440 宽度实测。**我没有原站截图，也没有做像素级逐页对比**；第 6 节只证明本地 36 页结构完整、数据呈现正确，不等于每页都和原站一致。

1. **指数范围与分组**：
   - 原站 63 只，本地 36 只，受数据包范围限制。
   - 原站「行业指数」是申万一级行业，按 6 条产业链子组（消费 / 医药 / 科技 / 金融地产 / 制造与装备 / 周期与资源）展开收起；本地是 10 只中证全指一级行业，没有子组。

2. **路由**：原站详情不改 URL；本地按任务要求保留 `#/index/<code>`，因此有返回钮和面包屑。
3. **顶栏内容**：原站顶栏是全站导航（本地没有对应站点）；本地顶栏放的是数据包日期、导入和导出。
4. **温度计**：
