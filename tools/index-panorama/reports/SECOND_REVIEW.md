## 二审发现与修复

1. **区间最大回撤计入窗口前高点**：已改为所选区间单独计算，全历史结果另列。回归例 `[100; 窗口80,90,85]` 的区间最大回撤为 -5.5556%，全历史 -20%。
2. **CSV 原型属性代码导致崩溃**：`constructor`、`toString` 等外部代码键已改无原型字典处理。
3. **跨来源 PE/PB 混拼**：导入这两列时整列替换，只用本次 CSV 的观测，来源和规则在页面说明。
4. **新导入日期被旧截止日截掉**：统计锚点现在按实际观测更新，原数据包日期与会话导入日期分别呈现。
5. **中证错误响应可能被当成空数据**：显式非成功 code 或 success:false 都拒绝，不污染已有数据。
6. **来源表述过度**：保留历史缓存的价格标签明确为“本地历史缓存 + 腾讯证券”，缓存原上游未全面验证；“没有免费可靠来源”改为“本版尚未接入可靠来源”。
