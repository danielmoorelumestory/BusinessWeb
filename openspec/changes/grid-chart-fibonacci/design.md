## Context

价格图由手写 SVG 的 `renderEquityChart` 绘制，已有手动支撑/压力色带（`Levels`）、K 线与区间选择。记录整份 JSON 存取，新增可选字段无需改接口。需求里的「AI」确认为本地算法（用户选择 1A），斐波那契位与手动区间互不混用（2A），用两个勾选框控制显示。

## Goals / Non-Goals

**Goals:**
- 用起点/终点价格确定性地算出回撤与延长位，并绘制在价格图上。
- 自动设置能自行选回看天数并识别波段；手动输入随时可覆盖。
- 两个勾选框分别控制手动区间与斐波那契的显示，状态随记录保存。

**Non-Goals:**
- 不调用大模型；不做周 K 级别识别。
- 不把斐波那契位写进手动区间，不参与网格计算与回测。
- 不提供多组斐波那契（每条记录一组）。

## Decisions

1. **数据结构**：`Fib = { start: {price, date?}, end: {price, date?}, extensions: {1.272: boolean, 1.382: boolean, 1.618: boolean}, lookback?: number }`；`View = { levels?: boolean; fib?: boolean }`。`view` 缺省时手动区间显示、斐波那契在已配置时显示。放在 `SavedRecord` 上，与 `levels` 同样整份同步。
2. **公式**：令 d = end − start。回撤价 = end − d × r（r ∈ 0.236/0.382/0.5/0.618/0.786）；延长价 = start + d × e（e ∈ 1.272/1.382/1.618）。上涨波段（end > start）延长线在终点之上，下跌波段在终点之下，两种方向用同一公式。起终点价格相同或非正数视为无效，给出错误提示。
3. **自动设置**：对候选回看 N ∈ {30, 60, 90, 120, 250}（不足 N 根时取全部），取最近 N 根日 K 的最高价与最低价所在的 K 线作为波段端点，方向由先后顺序决定（先低后高为上涨）。选择规则：从小到大找第一个振幅 (高−低)/低 ≥ 10% 且高低点不在同一根的窗口；都不满足时取振幅最大的窗口。该规则确定、可复现，结果回填输入框并在面板提示「已自动选取最近 N 日」。
4. **绘制**：斐波那契位画成细虚线，回撤位紫色、延长线玫红色，标签为「0.618  1.234」，放在图左侧与手动区间标签一致的位置并做防重叠；离当前纵轴范围很远的位不撑大纵轴，沿用手动区间的上/下边缘箭头提示。起终点日期在区间内时画两个小标记。
5. **显隐**：`renderEquityChart` 增加参数 `view` 与 `fib`；纵轴取值范围只考虑当前显示的叠加内容。勾选后立即重绘并保存（沿用 `pushRecord`，说明为「修正」）。
6. **为什么不用大模型**：服务端无模型密钥与调用链路，结果不可复现且有费用与延迟；本地规则已能满足「自选天数、自动设置起止」。

## Risks / Trade-offs

- 简单的最高/最低点识别在震荡行情里可能不是用户心目中的「主要波段」 → 自动结果只是起点，可手动改，面板显示所选天数。
- 叠加内容多时标签拥挤 → 复用防重叠，斐波那契标签更短，延长线可单独关闭。
- 记录同步的版本冲突沿用现有 `updatedAt` 机制，与手动区间一致。
