## Context

曲线由 `renderEquityChart`（手写 SVG）绘制：上图价格（收盘价折线 + 预计买卖线 + 步长虚线），下图资金，共用时间轴与十字光标。`series: EquityPoint[]` 全部来自 `calculateGrid` 对 `candles` 的逐日推进，回测只从建仓日开始。日线来源有两处：云端 Worker `/daily`（已返回 `open`）与腾讯接口直连（每行 `[日期, 开, 收, 高, 低, 量]`），前端解析时都丢弃了 `open`。实时报价 `mergeQuote` 也会构造 `Candle`。

## Goals / Non-Goals

**Goals:**
- 时间区间可设置，且可早于建仓日。
- 价格用日 K 展示，资金曲线数值不因区间而变。

**Non-Goals:**
- 周 K / 降采样（区间很长时 K 线会密，先不处理）。
- 分钟线、其他指标（均线、成交量）。
- 计算器页加区间控件。

## Decisions

1. **显示数据与回测数据分离。** 回测仍用 `getCandles(code, 建仓日)`，结果不变。图表另取显示用日线 `displayCandles`：起点取「区间起点与建仓日中较早者」，由 `getCandles(code, begin)` 获取（它已支持更早的起点并共享按代码的缓存）。这样回测规则、备份快照、对比曲线完全不受影响。
2. **x 轴以显示日线的日期为准。** `renderEquityChart` 新增参数：显示用 K 线数组与区间 `[from, to]`。点位按日期对齐：资金序列按日期查表，建仓日之前没有值，三条资金线从建仓日开始画（不补 0，不连线）。
3. **资金累计值不变（方案 A）。** 区间只决定显示哪些日期，不重算；纵轴范围按区间内可见的资金点计算，仍包含 0 轴。
4. **默认区间 = 建仓日至最新（与现在一致）。** 快捷按钮相对最新交易日计算，可早于建仓日；起止日期自动夹到「有行情的范围」（最早为取到的第一根日线，最晚为最新交易日）。起点晚于终点时提示并保持原区间。
5. **K 线配色：红涨绿跌（收盘 ≥ 开盘为红）。** 预计买入线由绿改为蓝色系、预计卖出线由橙改为紫色系，步长虚线同步；图例与 CSS 一并更新。十字光标提示框增加「开 / 高 / 低 / 收」。
6. **开盘价贯穿数据层。** `Candle` 增加 `open`；`downloadCandles`、`fetchDailyBars` 解析并带上 `open`；`mergeQuote` 合并当日时保留已有 `open`、新增当日时用实时报价的今开（腾讯报价字段 `fields[5]`），取不到则用现价兜底。`EquityPoint` 不变：K 线直接取显示用日线，不从 `series` 取（`series` 随记录保存，旧记录里没有开高低收）。
7. **本地缓存升到 v3。** 键前缀 `grid-trading-candles-v2:` → `v3:`，并像现有做法一样在模块加载时清理旧键，避免旧缓存缺开盘价。
8. **计算器页保持原样。** 它共用绘图函数，但不传区间、不显示控件；价格线同样变为 K 线。

## Risks / Trade-offs

- [区间早于建仓日需要多取日线] → 复用现有按代码缓存，云端覆盖不足时自动回退腾讯直连；请求失败时区间退回建仓日并提示。
- [全部区间 K 线较密] → 本次接受；后续需要再做周 K。
- [实时报价无今开时 K 线实体失真] → 用现价兜底，仅影响当日未收盘的最后一根。
- [换色改变既有视觉] → 只改买卖线与图例，随本变更一起核对。

## Migration Plan

纯前端变更：构建后随 Cloudflare Pages 部署；旧缓存键自动清理。回滚即回退提交。
