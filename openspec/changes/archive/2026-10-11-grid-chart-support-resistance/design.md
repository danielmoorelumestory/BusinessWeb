## Context

`SavedRecord` 整份 JSON 存进浏览器 localStorage 并同步到云端（Worker `records.payload` 原样保存，按 `updatedAt` 判断新旧），新增可选字段会自动随之保存与同步。价格图由 `renderEquityChart` 手写 SVG 绘制，已有预计买入线（蓝）、卖出线（紫）、步长虚线、红绿 K 线；右侧留白里已有「买 / 卖 + 价格」标签。详情页修改记录的通用模式是：`editRevision++`、更新 `updatedAt`、`saveRecord`、重绘、`pushRecord`。备份视图由 `backupRecordOf` 用备份快照包装出一条记录，目前不带记录上的其他字段。

## Goals / Non-Goals

**Goals:**
- 3 个支撑区间、3 个压力区间可设置、可显示、可跨设备同步。
- 不影响回测结果，不影响已有图表元素的可读性。

**Non-Goals:**
- 不参与网格计算或触发提醒。
- 不从分析报告自动导入区间（以后可做，数据结构保持够用）。
- 计算器页不支持。

## Decisions

1. **数据结构。** `Level = { low: number; high: number; note?: string }`；`Levels = { support: Level[]; resistance: Level[] }`，数组长度可变，每侧上限 `MAX_LEVELS = 10`，不含空项。`SavedRecord.levels?: Levels`；全部为空时保存为 `undefined`，不写空对象。早期按固定 3 项（含 `null`）保存的记录，读取时过滤掉空项即可兼容。
2. **输入与校验。** 设置面板放在曲线下方，支撑、压力各一个可增删的列表：每行为编号、下沿、上沿、备注和删除按钮，列表下方有「添加」按钮，达到上限时禁用。编号按列表顺序生成（S1、S2…），增删后自动重新编号；打开页面时没有区间的一侧默认显示一个空行。全空的行保存时忽略。规则：价格须为大于 0 的数字；下沿、上沿必须同时填写或同时留空；下沿不得大于上沿，违反时提示并不保存；上下沿相等视为一条线。支撑高于现价、压力低于现价只提示不拦截。区间之间允许重叠。
3. **保存。** 点「保存区间」后走通用修改流程：`editRevision++`、`updatedAt`、`saveRecord`、重绘曲线、`pushRecord`。区间不触发 `calculateGrid`。同步结果在设置面板里明确提示：先「已保存到本机，正在同步到云端数据库…」，成功后「已保存，并已同步到云端数据库」，失败或没有同步密钥时显示具体原因（`pushRecord` 增加提示用的称呼参数，默认值保持原有文案）。
4. **绘制。** `renderEquityChart` 增加可选参数 `levels`。每个区间画一个横贯价格图的半透明矩形加上下沿细线；上下沿相同时只画一条线。支撑用青绿色 `#0d9488`、压力用橙色 `#ea580c`，强度由区间自己的 `strength` 决定（见下一条），不再按列表顺序区分深浅。标签（如 `S1 4.95~5.00 备注`）画在色带内左侧，色带过窄时画在色带上方，不占用右侧已有的买/卖标签位置。
5. **强度。** `Level.strength?: 1 | 2 | 3`（弱 / 中 / 强），缺省为 2（中），旧记录无需迁移；`parseLevels` 总是写入强度，`normalizeLevels` 把不合法的值回落为 2。设置面板每行增加一个下拉（弱 / 中 / 强，默认中）。绘制时同时用三种视觉量表达，避免只靠颜色深浅难以分辨：填充透明度 0.07 / 0.15 / 0.26，边线宽度 0.6 / 0.9 / 1.6 且弱的用虚线，标签带星级（★☆☆ / ★★☆ / ★★★）；上下沿相同的价格线按强度取线宽 1.0 / 1.4 / 2.2。图例旁加一句「★ 越多越强」。
6. **纵轴范围。** 价格轴先按 K 线与买卖价算出可见范围，再把与「可见范围向两侧各扩 15%」有重叠的区间纳入纵轴；完全落在该范围之外的区间不画色带，改在图的上/下边缘画小箭头并标注编号与价格范围。这样远处的区间不会把 K 线压扁。
7. **与时间区间无关。** 色带横向铺满，不随时间区间变化。
8. **备份视图。** `backupRecordOf` 带上来源记录的 `levels`，备份视图只读显示，设置面板在备份视图里隐藏。
9. **颜色与图例。** 图例增加「支撑区间」「压力区间」两项色块；买入/卖出线、K 线配色不变。

## Risks / Trade-offs

- [价格图元素变多，标签可能重叠] → 标签放在色带内部左侧；多个区间靠得很近时标签按价格从高到低排列，重叠的依次下移 11px 避让。
- [区间与现价关系不合理（如支撑高于现价）] → 只提示不拦截，用户可能正需要这样标。
- [字段随整份记录同步，多设备同时编辑时后写者覆盖] → 与现有字段一致，沿用按 `updatedAt` 的新旧判断。

## Migration Plan

纯前端变更，随 Pages 部署；旧记录无 `levels`，行为不变；回滚即回退提交（已保存的 `levels` 字段对旧版本无影响，会被忽略并随整份记录保留）。
